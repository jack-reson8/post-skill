<sub>बिल्डिंग-इन-पब्लिक सीरीज़ ("Claude से उसकी अपनी $200 की सब्सक्रिप्शन वसूल करवाना") का दिन 1, इसी स्किल से बनाया गया।</sub>

AI से बनी ज़्यादातर पोस्ट इमेज एक ही तरह से फेल होती हैं: ग्रेडिएंट कार्ड, इमोजी की सूचियाँ, और ऐसा "डिज़ाइन किया हुआ" सीन जो दूर से टेम्पलेट लगता है। यह स्किल 7 बार असली रिजेक्शन ("भद्दा", "AI का बना लगता है", "Claude जैसा नहीं लगता", "बहुत गंभीर") झेलने के बाद बनी, जब तक सेट मंज़ूर नहीं हुआ। जिस तरीक़े ने इसे ठीक किया, वही यहाँ कोड किया गया है:

| चरण | Claude क्या करता है |
|---|---|
| 1 · ब्रीफ़ | `brief.md`: पोस्ट की GTM भूमिका, सीरीज़ की पहचान, और स्रोत सहित सच्चे तथ्यों की सूची — इमेज में इसके अलावा कुछ नहीं आ सकता |
| 2 · रेफ़रेंस | प्लेटफ़ॉर्म के सबसे ज़्यादा लाइक वाले कवर का ग्रिड बनाता है, अच्छे टेस्ट वाले ऐप्स के App Store स्क्रीनशॉट सेट पढ़ता है, और 3 सीख लिखता है (गेट) |
| 3 · स्टोरीबोर्ड | हर फ्रेम की एक पंक्ति: हेडलाइन, सबूत, तैरता कार्ड, जोक, GTM भूमिका। ज़रूरी: सीरीज़ लॉकअप वाला कवर, असली आउटपुट और कीमत वाला प्रोडक्ट फ्रेम, फ़ुल-ब्लीड नंबर पेज, फ़ॉलो हुक |
| 4 · कॉपी | पहले सीधी-सादी भाषा, फिर जोक लाइब्रेरी से 1–3 जोक (सवाल वाले टाइटल, एक-लाइन बीट, सपाट चेहरे का हास्य, कॉलबैक, उलटे अंत) |
| 5 · निर्माण | असली मोबाइल स्क्रीनशॉट, पिक्सेल-सटीक UI मॉकअप (X, Claude, iOS लॉक स्क्रीन, Google, Stripe), तालिका से अलग तरह के चित्र, App Store पोस्टर टेम्पलेट |
| 6 · समीक्षा | थंबनेल साइज़ पर कॉन्टैक्ट शीट, चेकलिस्ट के सामने जाँच |
| 7 · हैंड-ऑफ़ | शीट + 2–3 टाइटल विकल्प। पब्लिश करना हमेशा आपके हाथ में रहता है |

## इंस्टॉल

**Claude Code प्लगइन के रूप में (अनुशंसित)**

```bash
claude plugin marketplace add jack-reson8/post-skill
claude plugin install post@post-skill
```

**सामान्य स्किल के रूप में**

```bash
git clone https://github.com/jack-reson8/post-skill
cp -R post-skill/plugins/post/skills/post ~/.claude/skills/
```
हेडलेस रेंडरिंग के लिए Google Chrome और कॉन्टैक्ट शीट के लिए Pillow वाला Python 3 चाहिए।

**Codex (CLI या ChatGPT डेस्कटॉप ऐप):**

```bash
codex plugin marketplace add jack-reson8/post-skill
codex plugin add post@post-skill
```

या `plugins/post/skills/post` को `~/.codex/skills/` में कॉपी कर लें। यह स्किल खुले [Agent Skills](https://agentskills.io) मानक का पालन करती है, इसलिए Claude Code, Codex और SKILL.md पढ़ने वाले किसी भी एजेंट में चलती है।

**अन्य एजेंट (Cursor, Gemini CLI, GitHub Copilot और skills CLI द्वारा समर्थित अन्य एजेंट):**

```bash
npx skills add jack-reson8/post-skill
```
