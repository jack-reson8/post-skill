# 网感与小幽默：科技媒体和 X 华人账号怎么写得好玩（2026-10 研究）

目的：知识点一个不少，读起来轻松，像真人在聊，不像 AI 在汇报。一篇 1–3 个梗就够，多了就成段子手。

## 十个手法（每个都写清楚学谁、怎么用、我们的例子）

1. **反问式标题调侃**（量子位：大公司也 vibe coding 啊？）
   把事实写成一个带点幸灾乐祸的问句。
   例：花 200 刀请的 AI 员工 第一天就给我赚了 0 块？

2. **单句成段的停顿**（量子位：等一下。）
   在反转前放一句两三个字的独立段落，制造节奏。
   例：收入呢 / 0

3. **给现象起个名**（差评：套话文学；网友：XX 文学、XX 学）
   把一类行为命名，读者会记住、会转述。
   例：Claude 的拒绝文学 / 打工人 AI 版

4. **一本正经的离谱类比**（孙宇晨：父母对你的权力像联合国对美国）
   用很大的东西比很小的事，语气要严肃。
   例：它拒绝我的样子 像法务部突然附体

5. **轻描淡写的冷幽默**（CZ 出来第一条：能吃到不止一片水果 真是奢侈）
   大事小说，不加感叹号。
   例：第一天进账 0 元 比较稳定

6. **回敬梗 callback**（曾颖：把对方当年的"请你振作"原话还回去）
   前面埋一句，后面用同一句打回来。
   例：开头它说"我先去找真有人愿意付钱的需求" 结尾我说"需求找到了 人还没找到"

7. **谐音和双关**（曾颖：千万要开心 千万=一千万）
   只在顺手的时候用，硬凑就删。
   例：回本进度 0% 进度条很省电

8. **反差结尾**（量子位：不总结 用一个反差句收）
   结尾不升华，用一个和开头对比的小事实。
   例：260 个页面 0 个访客 页面比人多

9. **极简回复**（CZ 的 "4"）
   评论区回复可以只有一个字或一个数字，前提是粉丝懂。
   例：评论问"赚了吗" 回"0"

10. **假设式钩子**（邵艾伦：如果回到 20 岁 没人脉没资源 X 会怎么重新开始）
    用"如果…会怎样"开题，再给一个具体的时长或成本背书。
    例：如果只给 AI 一个 200 刀的会员 它能不能自己养活自己

## 用法
- 先写人话版（SKILL.md 的步骤），再挑 1–3 处换成上面的手法。
- 梗服务于事实：每个梗后面必须跟着真的数字或真的事。
- 不拿真人隐私开玩笑，不碰别人的恋爱八卦，不骂人。学的是句式，不是内容。
- 仍然不要 emoji、不要金句升华、不要"家人们""绝绝子"这类过时口癖。
